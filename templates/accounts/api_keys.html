Integration Guide

Use your API key to verify certificates directly from your website or application backend.

Endpoint
POST /api/v1/verify/
JavaScript (Fetch) Example
const verifyCertificate = async (hash, name) => { const res = await fetch('{{ request.scheme }}://{{ request.get_host }}/api/v1/verify/', { method: 'POST', headers: { 'Content-Type': 'application/json', 'X-API-Key': 'hd_YOUR_API_KEY' }, body: JSON.stringify({ cert_hash: hash, fields: { name: name } }) }); return await res.json(); };

Expected Response (Valid)

{ "valid": true, "certificate_id": "...", "recipient": "Rahul Sharma", "issued_at": "2024-03-21", "organization": "{{ request.user.name }}" }

Expected Response (Invalid)

{ "valid": false, "reason": "Details do not match certificate: name" }
